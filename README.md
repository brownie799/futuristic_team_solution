# 🚀 FUTURISTIC — ACCkart Decision Intelligence

**FUTURISTIC** is a data-driven decision intelligence platform built for the **ACCkart ₹10 Lakh Decision Hackathon**.

It analyzes orders, customers, products, marketing, returns, and delivery data to identify business opportunities and create an evidence-based **₹10,00,000 investment strategy**.

* 💰 ₹23.26 Cr net revenue
* 📈 ₹1.14 Cr recorded profit

* 🛒 Grocery ≈ −₹3.67L recorded profit
* 🚚 West delivery delay ≈ 93.7%
